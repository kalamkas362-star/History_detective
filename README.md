# HISTORY DETECTIVE — ҚҰПИЯ ІС №1839

Қазақ тіліндегі 45 минуттық дүниежүзі тарихы сабағына арналған интерактивті оқу ойыны. Қазіргі нұсқа — **жергілікті DEMO MODE прототипі**: негізгі ойын ағыны браузерде жұмыс істейді, деректер `localStorage` ішінде сақталады. Бұл толық өндірістік multi-device жүйе емес; төмендегі Supabase SQL/Edge Function — серверлік интеграцияны қосуға арналған бастапқы негіз.

## Іске қосу

Талаптар: Node.js 20.19+ немесе 22.12+.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Vite көрсеткен мекенжайды ашыңыз. Демо режимі Supabase/OpenAI кілттерінсіз іске қосылады. Мұғалім демо коды: `1839`. Бастапқы сессия коды: `1839`.

## Негізгі мүмкіндіктер

- Кинематографиялық басты бет және ережелер.
- Оқушының сессия коды, топ атауы, лақап аты және A/B/C деңгейі арқылы кіруі.
- Төрт миссия: сауда мен күміс, Линь Цзэсюй/1839, Нанкин келісімі, Екінші апиын соғысы.
- Детерминдік жауап тексеру, ишаралар, дәлел дәптері және ұпай.
- Қазақша scripted AI-архивші демосы; API кілті браузерге жіберілмейді.
- Мұғалім панелі: демо кіру, сессия құру, QR код, таймер, миссия ашу, командалар, ұпай түзету, CSV экспорт.
- Проектор режимі, тарихи дереккөздер беті, фактчекинг мазмұны, қолжетімділікке арналған үлкен мәтін және reduced-motion.
- Төрт миссия, дереккөздер мен интерфейс мәтіндері бөлек модульдерде.
- Мұғалім панелінен ашылатын 7-сыныпқа арналған қосымша сабақ материалы: Азия мемлекеттерінің әлеуметтік құрылымы, миссионерлік, отаршылдық ықпал және экспорт/импорт/экспансия/отарлау/фактория тапсырмалары; жауап кілттері және басып шығаруға арналған нұсқа.

## Environment

`.env.example` көшірмесін `.env.local` деп атаңыз.

- `VITE_SUPABASE_URL` — Supabase Project URL (серверлік интеграцияны іске қосқанда).
- `VITE_SUPABASE_ANON_KEY` — Supabase publishable/anon key; RLS міндетті.
- `OPENAI_API_KEY` — **тек Supabase Edge Function secrets ішінде** орнатылады. Бұл айнымалыны `VITE_` префиксімен ешқашан сақтамаңыз.

## 7-сыныптың қосымша сабақ материалын ашу

1. Сайтты іске қосып, басты беттен **МҰҒАЛІМ ПАНЕЛІ** бөліміне кіріңіз.
2. Демо кодын `1839` деп енгізіңіз.
3. Мұғалім панелінің төменгі жағындағы **7-СЫНЫП САБАҚ МАТЕРИАЛДАРЫ** батырмасын басыңыз.
4. Төрт оқу мақсатының тапсырмаларын ашып көріңіз. Мұғалімге арналған жауап кілттері әр бөлімнің төменгі жағында жасырылған; **Басып шығару** батырмасы браузердің басып шығару терезесін ашады.

## Supabase орнату

1. Supabase жобасын жасаңыз.
2. `supabase/migrations/001_initial.sql` файлын SQL Editor арқылы орындаңыз.
3. Authentication ішінде мұғалім аккаунтын жасаңыз. Өндірістік нұсқада teacher identity тек Supabase Auth арқылы тексерілуі керек.
4. Edge Function-ды `supabase/functions/archivist` ішінен deploy етіңіз және `OPENAI_API_KEY` secret орнатыңыз.
5. Клиенттегі `VITE_SUPABASE_URL` және `VITE_SUPABASE_ANON_KEY` айнымалыларын толтырыңыз.
6. Қазіргі UI-де нақты multi-device синхрондау толық қосылмаған; SQL/Edge Function бұл интеграцияға негіз болады, бірақ production-ready деп есептелмейді.

## GitHub Pages

1. Репозиторий атауын `history-detective-1839` етіп жасаңыз немесе `vite.config.ts` ішіндегі `base` мәнін өз repo атауыңызға бейімдеңіз.

4. GitHub Pages-тағы статикалық frontend-ке құпия кілттер салмаңыз. Supabase Edge Functions серверлік AI сұрауларын қабылдайды.

## Тарихи дәлдік туралы

Мәтіндер оқу мақсатындағы мазмұндама. Линь Цзэсюймен сұхбат — симуляция, тарихи тұлғаның нақты сөзі емес. Нанкин келісімі апиын саудасын өздігінен заңдастырған деп көрсетілмейді. Сабақ алдында мұғалім Britannica және шарт мәтіндерінің сенімді басылымдары арқылы мазмұнды тексеруі керек.
